Lesson 12 API Notes

Endpoint:  GET /flag
Host:      http://localhost:8080

Query parameters:
- token (required): the server only answers when you supply the
  correct token. Think about what names this course's server: the
  token is the word that identifies this lesson's service.

Logs:
- Access logs are written to /var/log/lesson12_access.log

Expected response:
  FLAG{...}
