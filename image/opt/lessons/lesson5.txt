Lesson 5: Text Viewing, Redirection, and Pipes
══════════════════════════════════════════════

OBJECTIVE
  View text, filter with grep, and redirect output.

LEARN
    cat FILE        → print everything
    less FILE       → page through (q to quit)
    head FILE       → first 10 lines
    tail FILE       → last 10 lines
    grep PAT FILE   → print lines matching a pattern
    wc -l FILE      → count lines
    CMD > FILE      → write CMD's output to FILE (overwrite)
    CMD >> FILE     → append output to FILE
    CMD1 | CMD2     → pipe: feed CMD1's output into CMD2

  Pipes chain tools together. Example:
    cat FILE | grep hello | wc -l
  counts the lines containing "hello".

TASK

  carry the marker word FLAGLINE — but only ONE of them holds the real
  flag; the others are decoys. Find the real one, save it to
  ~/lesson5_flag.txt, and read it.

KEY TAKEAWAY
  grep + pipes + redirection let you sift oceans of text in one line.
